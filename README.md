# About
**Bionic Rebirth** is a story based game with some puzzle elements. The game was made for [ZenoJam 7](https://itch.io/jam/zeno-jam-7) and also features a [Steam Release](https://store.steampowered.com/app/1916320/Bionic_Rebirth/).

## Built with
- Unity 2021.3.0f1
